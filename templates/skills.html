Skills

A skill tells CodeLens which knowledge-base files and which web docs to use for a kind of work — backend, UI/UX, debugging, agents — plus how to answer. Trigger one by typing /name at the start of a Chat message or the problem box.

Or write one
File format

name — lowercase with dashes; you type it after /.
description — shown in the / menu.
docs — knowledge-base titles to search (wildcards like python_* work). Leave it out to search all docs.
urls — public documentation pages fetched into the knowledge base and searched with this skill.
Everything after the second --- is instructions the AI follows while the skill is active.
